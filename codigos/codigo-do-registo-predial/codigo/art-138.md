# Artigo 138.º

Sigilo 1. A comunicação ou a revelação dos dados pessoais registados na base de dados só podem ser efectuadas nos termos previstos neste Código.

2. Os funcionários dos registos e do notariado, bem como as pessoas que, no exercício das suas funções, tenham conhecimento dos dados pessoais

registados nas bases de dados do registo predial, ficam obrigados a sigilo profissional, nos termos da Lei de Protecção de Dados Pessoais.
