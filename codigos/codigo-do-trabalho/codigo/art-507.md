# Artigo 507.º (Protecção dos olhos)

1. Os trabalhadores expostos a riscos de acidentes mecânicos, acções ópticas, radiações e lazeres e as acções químicas deverão proteger os olhos com equipamento adequado.

2. Para as acções mecânicas, os trabalhadores devem utilizar óculos de segurança.

3. Para as acções ópticas, os trabalhadores deverão utilizar óculos com vidros coloridos ou filtros apropriados.
